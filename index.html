📅 Google Calendar

Not connected

One-time setup (2 min) — get a free Client ID
  1. Go to console.cloud.google.com → create a free project.
  2. Enable the Google Calendar API and the Google Drive API (Drive is used for cloud sync).
  3. APIs & Services → OAuth consent screen → External → fill name/email → add yourself as a test user.
  4. Credentials → Create OAuth Client ID → type Web application.
  5. Add your app's origin (where you host this file, e.g. http://localhost:8080 or your HTTPS domain) to Authorized JavaScript origins.
  6. Paste the Client ID below. It stays on your device only.
